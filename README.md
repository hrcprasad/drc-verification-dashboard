# drc-verification-dashboard
Drag and drop a DRC .rpt file and then visualize DRC results by category
| Feature | v1 | v2 |
|---|---|---|
| File upload | Single | Multi-file |
| Charts | Static bar | Interactive Plotly |
| Data table | Basic | CSV export |
| Run comparison | ❌ | Side-by-side ECO table |
| Trend analysis | ❌ | Convergence line chart |
| Prediction | ❌ | "Clean DRC in ~N more runs" |
